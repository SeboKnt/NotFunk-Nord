Langstrecken-Netzwerk für Notfälle

⚠ Rechtlicher Hinweis

LoRa funktioniert in den ISM-Bändern (Industrial, Scientific, Medical). Die Sendeleistung ist auf 14 dBm (25 mW) begrenzt, bei Verwendung von Richtantennen darf auf bis zu 26 dBm (400 mW) erhöht werden. In Deutschland sind 868 MHz für LoRa offiziell zugewiesen.

LoRa Mesh-Netzwerk

Ein Mesh-Netzwerk verbindet mehrere LoRa-Knoten ohne zentrale Infrastruktur. Jede Station repeate Nachrichten an andere Stationen - so entsteht ein dezentrales Kommunikationsnetzwerk, das auch bei Stromausfall funktioniert.

🔧 Wie funktioniert Mesh?

Jedes LoRa-Gerät kann als Router fungieren. Nachrichten werden von Knoten zu Knoten weitergeleitet (Hop-by-Hop). So können Daten über große Distanzen übertragen werden, ohne dass eine zentrale Infrastruktur nötig ist. Protokolle wie LoRaWAN oder Meshtastic ermöglichen dies.
